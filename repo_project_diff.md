# GitHub Project vs Repository

## Difference Between GitHub Project and Repository

| GitHub Repository                                    | GitHub Project                                           |
| ---------------------------------------------------- | -------------------------------------------------------- |
| A repository stores **code and files**.              | A project helps **plan and manage work**.                |
| It contains files, folders, commits, and branches.   | It contains tasks, issues, pull requests, and notes.     |
| It is mainly used for **writing and managing code**. | It is mainly used for **organizing and tracking tasks**. |
| Example: `my-portfolio`                              | Example: `Portfolio Development`                         |
| Uses Git for version control.                        | Works like a project-management board.                   |

---

## 1. GitHub Repository

A **GitHub Repository (Repo)** is a place where you store and manage your project files and code.

### Example

```text
my-portfolio/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

A repository is useful for:

* Storing source code
* Tracking changes using Git
* Managing branches
* Collaborating with others
* Sharing projects on GitHub

---

## 2. GitHub Project

A **GitHub Project** is a tool used to plan, organize, and track work.

### Example

```text
Portfolio Development

☐ Create homepage
☐ Design navbar
☐ Add responsive layout
☐ Add GitHub statistics
☐ Deploy website
```

Tasks can be organized into different stages:

```text
TODO          IN PROGRESS          DONE
────────────────────────────────────────
Navbar        Homepage             README
Footer        Responsive CSS       Git setup
```

---

## How They Work Together

A GitHub Project and Repository can be connected.

```text
GitHub Project
"Portfolio Development"
        │
        ├── Create navbar
        ├── Add dark theme
        └── Deploy website
                 │
                 ↓
GitHub Repository
"angel-portfolio"
        │
        ├── index.html
        ├── style.css
        └── script.js
```

## Simple Difference

> **Repository = Where your code lives 📁**

> **Project = Where you manage your work 📋**

## Conclusion

A **GitHub Repository** is used to store and manage the actual project files and code, while a **GitHub Project** is used to organize tasks and track the progress of the project.
